## Observations and safety

- Read-only preflight passed before execution. Complete byte-preserving source copies were staged in exclusive
  capture folders; the local source copies were marked read-only. Parameter paths refer only to staged files.
- Each run wrote `catchment_storm.out` and `reference.log` in its capture cwd. Stdout/stderr were empty.
  Successful logs contain four bytes; no CSV was emitted. Failure text appeared in the log/report.
- All 1,938 original ensemble-directory file hashes and membership matched before/after the campaign.
  Staged/source mutation checks and offline manifest audits also passed. This is evidence for the inspected
  directories, not OS-wide write tracing or a guarantee against every possible indirect native file reference.
- Flag 1 echoed constant loss, IL in mm and CL in mm/h; flag 2 echoed runoff coefficient with IL=20 and
  coefficient=0.50. The supplied example's flag-2 coefficient of 2 was **not executed** as a valid case.
  Preflight now rejects coefficients above 1, with focused bounds/no-side-effects tests.
- Rainfall is labelled as applying in the increment following the printed rainfall time. Hydrograph rows are
  Inc 1..301, Time 0.50..150.50, although the calculation header says 300 increments. The baseline peak row
  is Inc 74, Time 37.00, versus native summary time-to-peak 36.5 h. Retain both; no silent shift or canonical
  time-zero interpretation is accepted. CSV and GUI timing remain missing.
- Code 11 emitted labelled upstream, rainfall-excess, reach downstream/upstream and outlet series as
  Hyd001..Hyd005. Outlet ordinates match the baseline. The outlet-only checker reports `incomplete_output`
  for the additional columns, appropriately; this campaign does not extend supported code-11 parsing.
- Complete baseline/zero captures remain `captured_unverified` because legacy storm-generator revision is
  unknown. Flag 2 additionally retains its conservative native-semantics provenance gap. Independent inspection
  establishes an all-zero outlet table, without relabelling the immutable capture as an accepted golden.

## Local retained evidence

Ignored `.local/rorb-reference/` contains ten unique capture directories with original inputs, generated
parameters, raw outputs/logs, stdout/stderr and hashed manifests. `.local/native-inventory.json` lists all
case IDs, manifest locators/hashes, output hashes, parameters, columns, peaks and printed-grid integrals.
`.local/environment.json`, `source-before.json`, `source-after.json`, `wheel-validation.txt` and
`campaign-summary.json` retain environment, integrity and intermediate inspection evidence. The intermediate
summary precedes the code-11/wheel runs; `native-inventory.json` is the complete inventory.

`.local/ensemble-inventory.json` inventories 643 storm files; 640 have filename TP IDs and matching output
candidates. Three generic storm files have no inferred TP ID. Directory-relative event IDs preserve duplicate
names in different directories. These are candidate mappings, **not validated ensemble pairs**; no ensemble
calculation was performed and no mapping completeness or generator provenance claim is made.

## Quality evidence and remaining acceptance gates

Windows/Python 3.14.6: Ruff 0.16.6 lint/format passed; strict Pyright 1.1.414 reported zero errors/warnings;
pytest 9.1.1 passed all 33 tests, no skips. The first attempt failed collection before editable installation;
after the documented install the complete gate passed. Wheel build passed; the wheel was installed into a
fresh temporary venv outside the checkout, import location and `py.typed` verified, and its capture/audit APIs
executed genuine baseline and zero-runoff runs. No hosted automation was added or enabled.

Missing: observed GUI build and saved effective settings, GUI/CMD full hydrograph comparison, CSV timestamp
characterisation, multi-ISA mapping, a separate simple-catchment reference, reviewed time interpretation and
tolerance policy, complete original-generator provenance and permission-cleared distributable reference data.
The native corpus therefore remains local and S0 is **not proposed as fully accepted or closed**.
